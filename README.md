# 🏥 Hospital Management System

A web-based Hospital Management System designed to manage hospital information in a simple and organized way.

## 📌 Features

- 👤 Patient management
- 👨‍⚕️ Doctor management
- 📅 Appointment management
- 💊 Medicine management
- 💰 Billing management
- 📊 Hospital dashboard
- ➕ Add new records
- 🗑️ Delete records
- 🔗 Frontend connected with backend APIs

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## 🎯 Project Purpose

This project was developed as a practical software engineering project to understand frontend development, backend development, REST APIs, and connecting a web interface with a server.

## ▶️ How to Run

1. Open the project in Visual Studio Code.
2. Open the backend folder in the terminal.
3. Install the required dependencies.
4. Start the Node.js server.
5. Open the application in your browser.
